# 🌙 코골이 감지기

무료로 쓸 수 있는 코골이 감지 웹앱입니다. 설치할 앱이나 결제가 없고, 마이크로 들리는 소리를 **이 기기의 브라우저 안에서만** 분석합니다. 소리 파일은 저장하지 않으며 서버로 보내지 않습니다.

## 기능

- 마이크로 실시간 소리 크기와 최근 60초 그래프 표시
- 저주파·저음 위주 소리를 코골이로 판단해 구간 단위로 기록 (시작 시각, 길이, 세기)
- 민감도 조절 (1~10)
- 오늘 감지 횟수 / 오늘 코골이 누적 시간 / 전체 누적 표시
- 기록을 CSV 파일로 저장, 기록 삭제
- 가능한 경우 화면 꺼짐 방지(Wake Lock) 사용

## 사용 방법

### 1. 실행

마이크는 **보안 연결(HTTPS 또는 localhost)** 에서만 허용되므로 아래 중 하나로 여세요.

- **휴대폰에서 쓰기 (추천)**: 저장소를 GitHub Pages로 배포하고 HTTPS 주소를 휴대폰 브라우저로 여세요.
  저장소 Settings → Pages 에서 이 브랜치를 소스로 지정하면 됩니다.
- **PC에서 쓰기**: 저장소 폴더에서 아래 명령을 실행한 뒤 `http://localhost:8000` 을 여세요.

  ```bash
  npm start        # 또는: python3 -m http.server 8000
  ```

### 2. 침실에서 두는 법

- 휴대폰이나 노트북을 **머리맡 0.5~1m** 거리에 두세요. 너무 멀면 소리가 약해서 놓칩니다.
- 충전기를 연결하고, 화면이 꺼지지 않도록 설정하세요. 탭은 열어 둔 상태를 유지해야 합니다.
- 알림 소리와 진동을 끄면 오탐이 줄어듭니다.
- 시작 전 마이크 권한을 허용하세요.

### 3. 민감도

- **기준 +20dB (1)**: 큰 코골이만 잡음. 주변이 시끄러운 곳에 적합
- **기준 +12dB (5, 기본값)**: 대부분의 코골이를 잡음
- **기준 +8dB (10)**: 작은 소리까지 잡음. 오탐이 늘 수 있음

그래프의 노란 점선이 기준선입니다. 파란 선이 이 점선을 넘어 빨간 배경이 칠해지면 코골이로 판단된 구간입니다.

## 작동 원리

1. 마이크 입력을 약 0.1초 단위로 주파수 분석(FFT)합니다.
2. 각 순간에 대해 다음 세 조건을 모두 확인합니다.
   - 소리 크기가 평소 주변 소음(노이즈 플로어)보다 기준 dB 이상 큼
   - 에너지의 60% 이상이 60~500Hz 저주파 대역에 있음 (코골이는 저음 위주)
   - 소리의 주파수 무게중심이 700Hz 이하 (말소리, 고음 기계음 배제)
3. 조건이 0.8초 이상 이어지면 한 번의 코골이로 기록합니다. 0.4초 이하의 끊김은 같은 코골이로 합칩니다.
4. 노이즈 플로어는 주변 소음 변화에 따라 천천히 갱신되므로, 선풍기처럼 계속 나는 소리는 기준선에 흡수되어 무시됩니다.

오디오 처리 중 에코 제거, 노이즈 억제, 자동 이득을 **끄도록** 설정했습니다. 노이즈 억제 기능이 켜져 있으면 코골이 소리가 함께 깎여 감지가 잘 안 되기 때문입니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면과 마이크 처리, 기록 저장 |
| `detector.js` | 감지 알고리즘 (브라우저와 Node 양쪽에서 동작) |
| `test/detector.test.js` | 감지 알고리즘 단위 테스트 (합성 신호 기반) |
| `package.json` | `npm test`, `npm start` 스크립트 |

## 테스트

```bash
npm test
```

합성 신호로 2초 코골이 감지, 짧은 소리 무시, 짧은 끊김 병합, 말소리·고음 소음 배제, 선풍기 등 지속 소음 무시, 민감도 동작을 확인합니다.

## 한계

- **참고용 기록 도구입니다.** 수면무호흡증 등 의학적 진단을 대신하지 않습니다.
- 마이크로 소리만 듣기 때문에 **코골이 소리가 아닌 숨소리·대화·TV 소리가 오탐될 수 있습니다.**
- 숨이 멈춘 구간(무호흡)은 소리로 직접 판단할 수 없습니다. 기록의 "코골이가 갑자기 멈추고 조용해진 뒤 크게 숨을 쉬는" 패턴은 참고 자료로 쓸 수 있습니다.
- 탭이나 브라우저를 완전히 닫거나, 기기가 잠들면 기록이 중단됩니다.
- 기록은 **이 브라우저에만** 저장됩니다. 다른 기기와 동기화되지 않으니 필요하면 CSV로 내보내세요.
- 주변 소음이 크면 민감도를 낮추세요.
